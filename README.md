
# 🏦 Bank Loan Analysis Project (Excel & SQL)

## 📌 Project Overview
This project focuses on analyzing **bank loan data** to uncover insights into **loan approval trends, borrower risk profiles, repayment behavior, and overall portfolio health** using **Microsoft Excel and SQL**.

The analysis simulates a **real-world banking analytics workflow**, helping financial institutions make **data-driven lending decisions**, reduce risk, and improve profitability.

---

## 🎯 Business Problem
Banks manage large volumes of loan applications and must:
- Evaluate borrower credit risk accurately
- Reduce loan defaults
- Improve loan approval accuracy
- Maintain a healthy loan portfolio
- Meet regulatory and compliance requirements

This project supports these objectives through structured data analysis.

## 📂 Dataset Description
The dataset includes:
- Loan ID  
- Address State  
- Employee Length  
- Employee Title  
- Grade & Sub Grade  
- Home Ownership  
- Issue Date  
- Loan Status  
- Annual Income  
- Debt-to-Income Ratio (DTI)  
- Interest Rate  
- Loan Amount  
- Monthly Installment

## 💡 Key Insights
- Borrowers with **lower DTI ratios** show reduced default risk  
- **Higher credit grades** receive better loan terms  
- **Stable employment history** correlates with stronger repayment behavior  
- Certain regions display higher default concentration
